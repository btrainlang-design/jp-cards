# 일본어 카드

영상 자막으로 만든 일본어 업앤다운 암기 카드. 오프라인에서도 작동하는 웹앱입니다.

## 새 테마 추가하는 법
1. `decks/<테마이름>/` 폴더에 `deck.json`, `voice-ai.json`, `voice-momo.json` 세 파일을 올립니다.
2. `decks/index.json`의 `decks` 목록에 한 줄을 추가합니다.
3. 이미 있는 테마의 카드를 고쳤다면 그 테마의 `v` 숫자를 1 올립니다. 그래야 휴대폰이 새 파일을 다시 받습니다.

앱 화면(index.html, sw.js)은 건드릴 필요가 없습니다.
